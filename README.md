# 🛒 Amazon Clone

A simple Amazon homepage clone built using **HTML** and **CSS**.  
This project focuses on layout design, styling, and UI structure.


## 📌 Features

✅ Responsive navigation bar  
✅ Search bar UI  
✅ Hero section  
✅ Product grid layout  
✅ Footer section  
✅ Hover effects  



## 🛠 Technologies Used

- HTML5
- CSS3
- Font Awesome (for icons)
